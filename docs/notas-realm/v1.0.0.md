# v1.0.0: primeira release

Non hai pasos a man. É a primeira versión publicada: toda instalación parte dela e Keycloak importa o realm `furar` desde cero no primeiro arranque (`deploy/keycloak/import/furar-realm.json`).

Comprobación (opcional): `scripts/comprobar-realm.sh --vivo` no servidor, que fala con Keycloak polo porto local 8082 (desde outro equipo, cun túnel SSH a ese porto; [`docs/instalacion.md`](../instalacion.md), §5).
