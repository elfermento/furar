# v0.1.0: primeira release

Non hai pasos a man. É a primeira versión publicada: toda instalación parte dela e Keycloak importa o realm `furar` desde cero no primeiro arranque (`deploy/keycloak/import/furar-realm.json`).

As notas con data deste cartafol (`AAAA-MM-DD-tema.md`) son probas do desenvolvemento anteriores a esta versión: xa están no realm importado e non se aplican a ningunha instalación.

Comprobación (opcional): `scripts/comprobar-realm.sh --vivo` no servidor, polo túnel da consola de administración ([`docs/instalacion.md`](../instalacion.md), §5).
